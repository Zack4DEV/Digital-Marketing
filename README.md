📱 Digital Marketing Platform for Influencers

A modern and interactive digital marketing app built with Streamlit, designed to help influencers and marketers optimize campaigns, leverage AI tools, and analyze performance with ease.

> 👤 GitHub: [@Zack4DEV](https://github.com/Zack4DEV)

---

🚀 Project Overview

This mobile application serves as a comprehensive campaign management tool tailored for influencers and content creators. The primary goals include:

- 📊 Streamlining campaign workflows
- 🤖 Integrating AI-driven assistance
- 📈 Enhancing analytics and performance monitoring
- 💡 Improving overall user experience and engagement

Built using:
- Streamlit for interactive backend analytics.
- Mendable AI Agent Assistant API for intelligent support integration (partial).

---

🎯 Key Features & Goals

✅ User Interface & Experience
- Refined UI across screens to ensure intuitive navigation and engaging visuals.

✅ Advanced Analytics & Reporting

- In-depth performance tracking with potential integration of dashboards using Streamlit.

✅ Machine Learning Integration (In Progress)
- Use of ML models for campaign optimization and user behavior predictions.

✅ 3rd Party Integrations
- Mendable AI Assistant partially integrated via:
  - utils/llmClient.jsx
  - components/AiAssistant.jsx
